# Data and Code Availability — v1.0.1

The public [v1.0.1 reproducibility artifact](https://github.com/Kane11378/representation-upgrade-label-revision/tree/v1.0.1) contains the code,
verification scripts, machine-readable derived result tables and protocol
metadata supporting the study. Third-party datasets, pretrained model weights and large cached arrays are not
redistributed; obtain them from their official sources or reproduce them using
the recorded identities and instructions. Source code whose redistribution
rights are not established remains excluded. The artifact provides accepted
analysis/confirmation code and lightweight verification of reported results;
a fully portable one-command scientific rerun across the original encoder and
cache-generation environments is not claimed.
